# FreeSans font assets

`FreeSans-Regular.otf` and `FreeSans-Bold.otf` are bundled from the GNU
FreeFont project. They are licensed under GPL-3.0-or-later with the GNU Font
Embedding Exception. Source: https://www.gnu.org/software/freefont/.

The render pipeline reads these files from this directory at runtime. It does
not fetch fonts, images, or other assets over the network.
